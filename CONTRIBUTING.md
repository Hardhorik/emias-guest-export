# Участие в разработке

Спасибо за помощь. Перед pull request выполните:

```powershell
npm ci
npm run check
```

Не добавляйте в репозиторий реальные гостевые ссылки, коды доступа, номера полисов, ФИО, медицинские документы, `manifest.json` из настоящей выгрузки или браузерные журналы. Для тестов используйте полностью вымышленные данные.

В описании ошибки укажите версию Node.js, операционную систему, команду запуска без ссылки и кода, код завершения и обезличенную часть сообщения. Если проблема связана с новым видом карточки ЕМИАС, опишите структуру элементов без персональных данных.

Изменения логики обхода страниц должны сохранять три свойства: скрипт не объявляет неполный раздел завершённым, не перезаписывает одноимённые документы и позволяет продолжить выгрузку после прерывания.
