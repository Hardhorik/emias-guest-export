# EMIAS Guest Export

Неофициальный локальный экспортёр документов из гостевого доступа к электронной медицинской карте ЕМИАС. Скрипт принимает гостевую ссылку и пятизначный код, скачивает доступные документы, раскладывает их по датам и категориям и создаёт ZIP-архив.

Проект не связан с Департаментом здравоохранения Москвы или разработчиками ЕМИАС. Используйте его только для карты, к которой у вас есть законный доступ.

## Что умеет

- выбирает период «всё время» и обходит пагинацию;
- сохраняет анализы, приёмы, исследования, справки и медицинские заключения, больничные, выписки, вызовы скорой помощи и консилиумы;
- сохраняет вложения из раздела «Загруженные документы», включая несколько файлов в одной карточке;
- сохраняет «Информацию о здоровье» в JSON и PDF;
- выгружает все рецепты по датам: исходный JSON карточки и сформированный для чтения PDF;
- для ЭКГ выбирает заключение вместе с кардиограммой, когда ЕМИАС предлагает такой файл;
- сохраняет видимый текст рекомендации или события в HTML, если окно не содержит кнопки скачивания;
- добавляет к имени приёма дату, специальность и врача;
- не перезаписывает одноимённые документы;
- проверяет PDF и SHA-256 каждого файла;
- продолжает прерванную выгрузку и пропускает уже проверенные файлы;
- сверяет найденные записи со счётчиками ЕМИАС и сообщает о неполной выгрузке;
- по умолчанию блокирует сетевые запросы страницы ко всем доменам, кроме `lk.emias.mos.ru`.

Проект проверялся на карте с сотнями записей и несколькими страницами результатов. Интерфейс ЕМИАС может измениться, поэтому итоговый `manifest.json` является частью результата, а не отладочным файлом.

## Требования

- Node.js 20 или новее;
- npm;
- Chromium, Google Chrome или Microsoft Edge.

## Установка

```powershell
git clone <адрес-репозитория>
cd emias-guest-export
npm ci
npx playwright install chromium
```

Если Google Chrome уже установлен, Chromium можно не загружать и запускать программу с `--browser chrome`. Для Microsoft Edge используйте `--browser msedge`.

## Быстрый запуск

Самый безопасный вариант — интерактивный ввод:

```powershell
npm run download -- --browser chrome
```

Можно использовать переменные окружения. В PowerShell:

```powershell
$env:EMIAS_GUEST_URL = "https://lk.emias.mos.ru/guest?token=ВАШ_ТОКЕН"
$env:EMIAS_ACCESS_CODE = "12345"
npm run download -- --browser chrome
Remove-Item Env:EMIAS_GUEST_URL, Env:EMIAS_ACCESS_CODE
```

Ссылка и код поддерживаются и как аргументы, однако тогда они могут сохраниться в истории команд и отображаться в списке процессов:

```powershell
node emias-export.mjs "https://lk.emias.mos.ru/guest?token=ВАШ_ТОКЕН" --code 12345 --browser chrome
```

## Результат

```text
exports/
  emias_2026-09-09T10-30-00-000Z.zip
  emias_2026-09-09T10-30-00-000Z/
    Анализы/2024/2024-09-21__Общий анализ крови__0123456789.pdf
    Приёмы/2026/2026-01-19__Врач-терапевт__Иванов И. И__abcdef0123.pdf
    Исследования/2024/2024-10-23__ЭКГ, Врачебное заключение__123456abcd.pdf
    Справки/2024/2024-03-01__Рекомендация (текст страницы)__9876543210.html
    Загруженные документы/2024/2024-02-20__МРТ (снимок.jpg)__fedcba9876.jpg
    Информация о здоровье/2026/2026-09-09__Информация о здоровье — данные__0123456789.json
    Рецепты/2026/2026-08-21__Название препарата — рецепт__abcdef0123.pdf
    manifest.json
    README.txt
```

Структура — `Категория / Год / Дата__Описание__Короткий-ID.расширение`. Формат даты `ГГГГ-ММ-ДД` правильно сортируется по имени. Если дату нельзя распознать, используется папка `без-даты` и создаётся предупреждение.

PDF и изображения сохраняются в том виде, в котором их отдал ЕМИАС. HTML-файл содержит текст окна ЕМИАС и создаётся только тогда, когда у карточки нет скачиваемого файла. Это явно указано внутри HTML и в `manifest.json`.

`manifest.json` содержит статус разделов и документов, исходные подписи, относительные пути, размеры и SHA-256. Гостевая ссылка и код туда не записываются; сохраняется только SHA-256 ссылки, чтобы `--resume` нельзя было случайно применить к другой карте.

## Продолжение после сбоя или истечения сессии

Большая выгрузка может пережить истечение сессии ЕМИАС. Запустите команду снова с той же ссылкой, кодом и папкой:

```powershell
node emias-export.mjs --browser chrome --resume "exports/emias_2026-09-09T10-30-00-000Z"
```

Программа проверит сохранённые файлы по SHA-256, пропустит исправные и скачает отсутствующие или повреждённые. ZIP будет пересоздан после прохода.

## Параметры

```text
--out DIR             Папка для новых выгрузок; по умолчанию exports
--resume DIR          Продолжить существующую выгрузку
--browser NAME        chrome или msedge вместо комплектного Chromium
--headed              Показать окно браузера
--timeout MS          Таймаут операции; по умолчанию 45000
--uploads-only        Повторно обработать только загруженные документы; требует --resume
--health-only         Обработать только информацию о здоровье и рецепты
--allow-third-party   Разрешить странице сетевые обращения вне lk.emias.mos.ru
-h, --help            Показать справку
```

Коды завершения:

- `0` — все распознанные разделы и документы обработаны;
- `2` — архив создан, но есть недоступные документы, несовпадение счётчиков или разделы для ручной проверки;
- `1` — ошибка запуска, входа либо прерывание прохода.

## Ограничения

- Скрипт получает только данные, разрешённые гостевой ссылкой. Ответ ЕМИАС `HTTP 403` фиксируется как недоступный документ и не обходится.
- Снимки лучевой диагностики, для получения которых нужно нажать «Запросить изображение исследования», автоматически не запрашиваются. Уже прикреплённые пользователем изображения скачиваются.
- «Информация о здоровье» сохраняется в JSON без потери структуры и в PDF для чтения.
- «Рецепты» выгружаются за всё время: исходные данные каждой карточки сохраняются в JSON, а для чтения скрипт формирует PDF. Сам ЕМИАС в этом разделе не предоставляет готовый PDF. Полнота проверяется по счётчику раздела.
- «Дневник здоровья» и «Диспансеризация» пока не экспортируются. Их содержимое нужно сохранить отдельно через интерфейс ЕМИАС.
- Анкеты, графики и нестандартные новые разделы могут потребовать ручной проверки. Скрипт не объявляет неизвестный непустой раздел успешно выгруженным.
- Текстовая карточка без кнопки скачивания сохраняется в HTML, а не выдаётся за оригинальный PDF.
- ЕМИАС может изменить интерфейс и `data-testid`. При коде `2` или неожиданном количестве файлов сначала изучите `manifest.json`.

## Приватность и сеть

Скрипт работает локально, не содержит аналитики и не отправляет документы автору. По умолчанию браузер пропускает запросы страницы только к `https://lk.emias.mos.ru`; ссылки `data:`, `blob:` и `about:` разрешены для работы браузера. Подробнее: [SECURITY.md](SECURITY.md).

Во время установки `npm` обращается к реестру пакетов, а команда установки Chromium — к серверу загрузки браузера. Эти обращения происходят до запуска экспортёра и не содержат медицинских документов.

Папки `exports/`, `output/`, `.playwright-cli/` и `.env*` исключены из Git. Всё равно проверяйте `git status` перед публикацией.

## Разработка

```powershell
npm ci
npm run check
```

Тесты проверяют даты, имена врачей, безопасные пути Windows, различение одноимённых файлов, валидацию PDF и ZIP с кириллическими именами.

Сообщения об ошибках приветствуются, но используйте только обезличенные примеры. Не прикладывайте архив выгрузки, `manifest.json`, ссылку, код, номер полиса, ФИО или снимки экрана с медицинскими данными.
