# Безопасность и приватность

Этот проект работает с медицинскими данными. Не публикуйте гостевые ссылки, коды доступа, содержимое `exports/`, журналы браузера и созданные архивы.

По умолчанию страница в автоматизированном браузере может обращаться только к `https://lk.emias.mos.ru`. Запросы к другим доменам блокируются. Флаг `--allow-third-party` снимает это ограничение и нужен только при подтверждённой несовместимости.

Скрипт не отправляет документы разработчику и не использует аналитику. Все файлы остаются в выбранной локальной папке. Во время `npm install` npm обращается к своему реестру, а `npx playwright install chromium` — к серверам загрузки браузера.

Гостевая ссылка и код дают доступ к чувствительным данным. Передавайте их интерактивно или через `EMIAS_GUEST_URL` и `EMIAS_ACCESS_CODE`. Аргументы командной строки могут попасть в историю оболочки и список процессов. Ссылка не сохраняется в `manifest.json`: там хранится только её SHA-256 для безопасного продолжения той же выгрузки.

Если вы нашли уязвимость, не создавайте публичный issue с реальными медицинскими данными. Сообщите владельцу репозитория приватным каналом, указанным в профиле проекта, и приложите обезличенный пример.
